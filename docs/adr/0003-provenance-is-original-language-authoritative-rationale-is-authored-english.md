# Provenance stays original-language-authoritative; Rationale is separately authored English content

User-facing clinical content (Recommendation, Rationale, applicability explanation, endpoint labels, workflow text) is English, but several sources (the Local SOP, the German S3 guideline) are German-language documents. We considered treating an English rendering as if it were the source itself, but rejected it: that would make the audit trail unverifiable against the actual document and would blur translation into the provenance record. Instead we keep two distinct, explicitly linked things:

- **Provenance** identifies and locates the original-language source (document identity, version/publication date, original language, source type, and locator — section, recommendation number, table, figure, or page). This stays authoritative for verification. An original-language excerpt may optionally be attached when useful and permissible, but is never required — the system must not depend on copying copyrighted or internal source text into the public repository or production package.
- **Rationale** is the authored, versioned English clinical interpretation linked to that Provenance. It is application content, produced once at rule-authoring time by a human, never generated by runtime translation.

Conceptually: *original clinical source (German or English) → structured Provenance pointer → approved executable Atomic Clinical Rule → approved English Recommendation/Rationale.* The Rationale is downstream content derived from the source; it does not become the source.
